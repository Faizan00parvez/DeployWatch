The pipeline

Six stages, zero touch. From git push to a monitored production rollout.

01

Push

Code lands on main and the pipeline wakes up.

02

Test

GitHub Actions runs the pytest suite — a red build stops here.

03

Build & ship

Multi-stage Docker build, versioned by commit SHA, pushed to Docker Hub.

04

Sync

ArgoCD detects the new image tag and syncs the Helm chart to the cluster.

05

Deploy

Rolling update on Kubernetes with liveness/readiness probes and HPA at 70% CPU.

06

Observe

Prometheus scrapes metrics, Grafana renders them live. Failures roll back.
